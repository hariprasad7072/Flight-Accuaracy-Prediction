REST API Documentation

Base URL

http://localhost:5000

Endpoints

POST /predict

Make a flight delay prediction with form data.

curl -X POST http://localhost:5000/predict \
  -d "date=2026-04-15&time=14:30&airline=UA&origin=JFK&dest=LAX&distance=2500&temp=22&wind=15&precip=0&vis=10&hum=50&pres=1013"

GET /api/results

Retrieve all model evaluation metrics.

curl http://localhost:5000/api/results

GET /api/charts

List available visualization charts.

curl http://localhost:5000/api/charts

GET /api/charts/{filename}

Download specific chart image.

curl http://localhost:5000/api/charts/model_comparison.png

Response Format

{
  "success": true,
  "prediction": "ON TIME",
  "probability": 0.3234,
  "risk_level": "LOW",
  "explanations": [
    {
      "feature": "Precipitation mm",
      "impact": "decreased",
      "importance": 0.1523,
      "value": 0.0
    }
  ]
}
